# ☁️ CloudCalc Pro

CloudCalc Pro is a cloud-based calculator application that allows users to perform calculations, securely save their calculation history, and view personalized dashboard and analytics data.

## 🚀 Features

- 🔐 User Registration & Login
- 🧮 Online Calculator
- ☁️ Cloud-based data storage
- 📜 Calculation History
- 📊 Personal Dashboard
- 📈 Analytics
- 👤 User Profile
- ⚙️ Account Settings
- 📱 Responsive mobile-friendly UI
- 🔒 Supabase authentication and database
- 🎨 Modern 3D glassmorphism interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Responsive Design

### Backend
- Node.js
- Express.js
- REST API

### Database & Authentication
- Supabase
- PostgreSQL
- Supabase Authentication

- Git
